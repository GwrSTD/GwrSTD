#### Featured Project

**[Render Builds](https://github.com/GwrSTD/render-builds)** — Offline Rust-powered Android application that reconstructs 3D Minecraft Java (`.schem`) structures from front, side, and top photos using visual hull geometry, CIELAB block matching, layer-by-layer 2D editing, and native Android `MediaStore` export.
