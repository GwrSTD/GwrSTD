### Gunewr7 (`GwrSTD`)

Building offline-first Android applications, 3D geometry engines, and voxel schematic utilities in Rust.

---

#### Featured Project

**[Render Builds](https://github.com/GwrSTD/render-builds)** — Native Rust & Android 3D voxel schematic studio that reconstructs enclosed 3D buildings (`.schem`, Sponge v2 Gzip NBT) from a single photograph using on-device monocular depth (**Depth Anything V2 Small `ViT-S`**, Apache-2.0 via `tract-onnx`), Manhattan perspective calibration, optional BYOK Vision AI blueprint synthesis, procedural 16×16 WebGL 3D inspection, 2D layer editing, and direct Android `MediaStore` export.
