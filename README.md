### Gunewr7 (`GwrSTD`)

Building offline-first Android applications, 3D geometry utilities, and Minecraft Java tools in Rust.

---

#### Featured Project

**[Render Builds](https://github.com/GwrSTD/render-builds)** — Offline Rust-powered Android application that reconstructs 3D Minecraft Java (`.schem`) structures from a single photo using perspective vanishing-point calibration, automatic reference-block scaling, direction-aware neighbor lattice growth, CIELAB block matching, textured 3D inspection, 2D layer editing, and native Android `MediaStore` export.
